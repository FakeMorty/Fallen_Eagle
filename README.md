Компактный набор для передачи другому ИИ-агенту (или разработчику).
Всё текстовое, без PNG-диаграмм (они регенерируются из данных).

## Как читать `01_данные_мода.py`

Это объединение исходных файлов `gen_design.py`, `epoch2_data.py`, …, `epoch6_data.py`.

Хелперы:
- `S(color, text)` — терминальный выбор.
- `D(color, label, arc)` — решение с дугой.

Структуры (по эпохам):
- `EVENTS` — Эпоха 1 (1980–1991), список событий.
- Эпоха 2: `BRANCH_A` (СССР), `BRANCH_C` (ССГ), `BRANCH_B_RUSSIA` (Россия), `REPUBLICS_FULL` (14 республик).
- Эпоха 3: `BRANCH_A3`, `BRANCH_C3`, `BRANCH_B_RUSSIA3`, `REPUBLICS3`.
- Эпоха 4: `BRANCH_A4`, `BRANCH_C4`, `BRANCH_B_RUSSIA4`, `REPUBLICS4`.
- Эпоха 5: `BRANCH_A5`, `BRANCH_C5`, `BRANCH_B_RUSSIA5`, `REPUBLICS5`.
- Эпоха 6: `BRANCH_A6`, `BRANCH_C6`, `BRANCH_B_RUSSIA6`, `REPUBLICS6`, `GRAND_ENDINGS`.

Формат события:

```
{'year': '1982', 'title': '...', 'trigger': None,
 'decisions': [D(...), D(...), D(...)]}
```

где `D(color, label, arc)` и `arc = [(stage, subtitle, [S, S, S]) x3]`,
`stage` ∈ {НАЧАЛО, КУЛЬМИНАЦИЯ, ФИНАЛ}.

Цвета: `r` = 🔴 консерватор, `y` = 🟡 центрист, `g` = 🟢 реформатор.

## Ключевые правила (дублируются в ТЗ и дизайне)

- Каждое событие — ровно 3 решения.
- Каждое решение → дуга ①НАЧАЛО → ②КУЛЬМИНАЦИЯ → ③ФИНАЛ (последовательно).
- У каждого шага дуги — 3 терминальных решения (не ветвятся дальше).
- Метки/флаги и переходы — по `03_формат_событий.md`.
